1
「我的工具」→ 文件管理系統非結構化文件 → 知識庫

一鍵開啟文件管理系統（免再登入）。規章、SOP、合約、圖面上傳後自動建版本、控權限，並成為 AI 助理可以查詢的企業知識庫。

2
系統通知系統排程預警

排程定時掃描 ERP／資料庫，一旦符合條件（如進貨單價漲幅超過門檻）就主動推播，不必等人工翻報表才發現。

3
報價追蹤通知資料庫整合運用

直接讀取既有系統資料，找出「口頭報價未補單」「報價逾期未回覆」等狀況，提醒對應業務跟進。

4
門號續約通知程式開發包：Excel → 轉成系統

原本用 Excel 管理的清單（如門號合約），透過開發包轉成系統資料，到期前 60 天自動提醒負責人確認。

5
標案監控通知外部 AI Agent（MCP）

外部 AI Agent 透過 MCP 定期巡查政府採購網等來源，符合關鍵字的新公告整理成摘要推送進群組。

6
AI 助理／對話框 @AI問問題・交辦工作

在任何對話輸入「@AI」即可查文件、問數據、請 AI 起草回覆或建立待辦；也可以直接私訊「AI 助理」。

7
通知卡片看到就能處理

每則通知都帶有「發生什麼事、原因、負責人、行動連結」。點連結完成填報後，連結會變灰並標示 ✓，一眼看出哪些已處理。

典型操作情境

2採購漲價預警

  1. 排程每日比對進貨單價，漲幅超過門檻即觸發。
  2. 「系統通知」收到漲價卡片，含幅度與原因。
  3. 採購點「開啟填報頁面」，填寫因應方式。
  4. 送出後卡片標示 ✓，主管在同一畫面掌握進度。

16查規章、找文件

  1. 文件透過「文件管理系統」上傳、審核、發行。
  2. 同仁在對話框輸入「@AI 客訴處理流程最新版？」
  3. AI 助理回覆重點摘要，並附上文件連結。
  4. 依權限開啟正式版本，下載自動加浮水印並留紀錄。

4Excel 轉成系統

  1. 提供現有 Excel 清單（例如門號合約）。
  2. 以程式開發包轉成系統資料表與維護畫面。
  3. 設定提醒規則：到期前 60 天通知。
  4. 到期提醒自動出現在「門號續約通知」群組。

5外部標案監控

  1. 設定關鍵字（產品類別、機關、金額區間）。
  2. 外部 AI Agent 透過 MCP 定期巡查公告。
  3. 新公告整理成摘要，推送至「標案監控通知」。
  4. 業務在群組內討論、@AI 分析投標條件。
