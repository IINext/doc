# Home 主系統盤點

來源：`Home.xml`（Magic xpa 3.3，專案名稱 `Home`，約 157 MB；以 7z 壓縮上傳，原始檔沒有放進 repo）。

```
python magic_dump.py Home.xml                                   # 程式清單
python magic_dump.py Home.xml --out dump/home \
    --with Files.xml --with EDB.xml --with Project.xml --with Doc.xml \
    --with PLC.xml --with UserFunctionality.xml --with Chart.xml   # 全部展開，約 20 秒
```

## 轉換建議

- 各業務模組的單據大多是同一個模式：`單據(H)` 表頭 + `單據(D)` 明細 + 送簽（呼叫 EDB）。
  先挑一種單據（例如 H01 請假申請單）完整轉一次，建立共用的 Python 寫法，其他單據照著做。
- 「手機程式」是 Magic Mobile 的畫面，網頁版可以用響應式設計，不需要另外做一套。
- Main Program 定義了 140 個全域事件（`GUE_送簽`、`GUE_資料導出`、`GUE_手機收料`…），
  是各畫面共用的按鈕與快捷鍵，網頁版可以做成共用的工具列元件。

## 安全問題

轉換時**不可以**保留以下寫法；因為原始碼裡寫有密碼，也建議在現行系統上儘快處理。密碼內容不寫在這份文件裡。

| 問題 | 位置 |
|---|---|
| **萬用密碼**：任何帳號輸入同一組固定密碼就能登入 | Home #3 登入.手動登入、#12 Partner、#58 Logon、#60 PasswordCheck、#1264 手動登入、#1407 登入.一般權限確認、#1409 登入.螢幕保護、#2504 帳密檢查（供應鏈平台） |
| 另一組寫死的密碼 | Home #60 PasswordCheck |
| PDF 加密的擁有者密碼寫死 | Doc #52 PDFWatermark |
| 文件密碼以明文存放 | `DOC_DocByTool.Password` 欄位 |
| SQL 以字串組合參數（SQL injection 風險） | EDB 的 My*Records、Mesg* 等查詢（見 [`EDB.md`](EDB.md)） |
